Mental Health Score Prediction

A learning project that predicts a student’s mental-health score from lifestyle habits.

01 / CONTEXT

The opportunity.

Sleep, study habits, social media use and stress all change together. This project asks how well those habits predict a 0–10 wellbeing score, as a modelling exercise, not a medical tool.

02 / MY CONTRIBUTION

Where I came in.

I compared several models, tuned the best ones, and put the winner behind a web service with a simple page where anyone can try it.

03 / THE WORK IN PRACTICE

What got built.

Choosing the best model

I tested Random Forest, XGBoost and CatBoost against a simple baseline. The tuned Random Forest was the most accurate (R² about 0.83, average error about 0.42 points), clearly ahead of the baseline (about 0.74 and 0.54).

Tuning

Each model was tuned automatically over 100 trials with 5-fold cross-validation, a standard way to test on unseen data.

Putting it online

The saved model sits behind a FastAPI web service on Render. The free server sleeps, so the first load can take 30–60 seconds.

04 / THE BIGGER PICTURE

Why it matters.

The project is upfront about its limits: the 5,000-row dataset is synthetic-style and results vary slightly between runs, so it shows method, not diagnosis.
