01 / CONTEXT

The opportunity.

Employees ask IT support questions all day. A normal AI chatbot answers confidently even when it found nothing useful. This project adds a checking step, so the assistant only answers when it has good evidence.

02 / MY CONTRIBUTION

Where I came in.

I designed how the assistant thinks and decides, and built the backend, the document search, the admin upload feature and a simple chat page.

03 / THE WORK IN PRACTICE

What got built.

Understands the question

A router first decides whether a message is general conversation, which it answers directly, or an IT question, which needs a search of the company documents.

Checks its evidence

It finds the best-matching passages in a document library (a Pinecone vector database), and an AI grader marks them good or weak before any answer is written.

Never bluffs

If the documents are weak it searches the web and grades those results too. If the web is weak as well, it still gives its best answer and clearly says what is missing.

04 / THE BIGGER PICTURE

Why it matters.

Admins can upload PDF, Word, text and Markdown files through a protected page, so the assistant learns new material without any coding. Every run is logged, so its behaviour can be reviewed later.
