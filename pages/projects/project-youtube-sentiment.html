01 / CONTEXT

The opportunity.

YouTube comment sections are long and noisy. This project sorts comments into negative, neutral and positive, so a viewer can see the mood of a video at a glance.

02 / MY CONTRIBUTION

Where I came in.

I built it end to end: trained the model, set up a repeatable training pipeline, deployed it online and built the Chrome extension.

03 / THE WORK IN PRACTICE

What got built.

The model

Trained on 37,249 YouTube comments, it labels each one negative, neutral or positive. It was right 89.64% of the time on comments it had never seen (86.4% weighted F1).

Repeatable pipeline and deployment

Every step from raw data to trained model is automated and tracked, so results can be reproduced. The model runs as a web service on Amazon Web Services (AWS) inside a Docker container.

The Chrome extension

The extension reads the live comments on a video, asks the service to score them, and shows charts and word clouds in the browser.
